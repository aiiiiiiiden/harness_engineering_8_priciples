# ADR 0003 — 주제 전환: 12-Factor Agents → 하네스 엔지니어링(OpenAI)

- 상태: 채택
- 날짜: 2026-06-02
- 대체: 이 책의 골격 텍스트를 0001/0002의 전제에서 교체

## 맥락

초기 이 책은 HumanLayer의 **12-Factor Agents**(LLM 에이전트 *런타임* 설계 12원칙)를 골격으로 1부 3장(reviewed)·2부 골격까지 진행했다. 저자는 책의 논지를 OpenAI의 **Harness Engineering**(에이전트가 일하는 *코드베이스/개발환경* 설계)으로 전환하기로 결정했다.

판단 근거:
1. **서사 적합성.** 정본(빈 git 리포 → Codex 에이전트만으로 5개월간 ~100만 줄, 사람 손코딩 0줄)은 "빈 레포(L1)에서 시작해 원칙마다 키우는" 실습형 책 구조와 정확히 맞는다.
2. **메타 정합성.** 이 레포 자체가 이미 하네스 엔지니어링 원칙의 살아있는 예시다(CLAUDE.md 진입점·`verify.py` 기계적 강제·`verified-facts.md`/front-matter 기록 시스템·결정론적 렌더). 4부 자기채점이 더 자연스러워진다.
3. **전환 비용 최소.** 발행 0/24 시점이라 SoT·toc·원고를 갈아엎는 비용이 가장 싸다.

## 결정

1. **핵심 텍스트 교체.** HumanLayer 12-Factor Agents → OpenAI Harness Engineering(Ryan Lopopolo, `openai.com/index/harness-engineering/`, 2026-02-11). 12-Factor Agents·HumanLayer 참조는 본문·링크·참고문헌에서 **완전 제거**(denylist로 강제).
2. **8원칙은 정본에서 *도출*.** 정본은 서술형이라 원칙을 번호로 명시하지 않는다. 이 책은 정본의 **목차 절을 한 절당 한 원칙으로 도출**한 8원칙 커리큘럼으로 제시하고, 각 원칙을 정본 절에 1:1 접지한다. 본문은 "정본이 정한 8원칙"으로 단정하지 않고 **"정본에서 도출한 8원칙"** 으로 표기한다(13번째 factor를 "비정본"으로 다루던 기존 정직성 태도와 동일). 목록·순서는 `verified-facts.md` §2가 마스터.
3. **러닝 예제 = 새 샘플 프로젝트.** 빈 레포(L1)에서 시작해 원칙마다 한 층씩 키워 에이전트 친화 하네스(L5)로 만든다. 매 장 스코어카드 델타를 보여준다.
4. **구조 축소.** 2부 12장(factor) → 8장(원칙). 3부 패턴(4장)·4부 케이스(2장)는 유지하되 원칙 명칭으로 재정렬. 총 24장 → 20장. `toc.json`을 먼저 고치고 `scaffold.py` 재실행, 구 factor 원고는 삭제.

## 근거

- 정본이 공개 1차 출처(openai.com)라 `crosscheck.py`(codex)로 검증 가능 → 책의 절대 규칙 #1(출처 충실성)을 만족.
- "도출한 8원칙" 표기는 비정본 카운트를 정직하게 드러내 codex 게이트를 통과시킨다.

## 영향

- reviewed였던 ch01~03은 재작업(ch01 경미·ch02 전면·ch03 중간). 기존 커밋은 보존, 피벗은 새 커밋으로 덮음(히스토리 미변경, `pivot-harness-engineering` 브랜치).
- `verify.py` DENYLIST/OFFICIAL_DOMAINS, `conventions.md` 용어표, `CLAUDE.md`/`BOOK_PLAN.md` 전제 동시 갱신.
