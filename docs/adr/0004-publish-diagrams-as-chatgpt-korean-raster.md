# ADR 0004 — 본문 다이어그램 발행본을 ChatGPT 한국어 래스터로 채택

- 상태: 채택
- 날짜: 2026-06-04
- 관련: ADR 0002(교차검증·이미지 = SVG 결정론 렌더)를 **부분 수정**. CLAUDE.md Rule 4·`conventions.md` §8(a) 동시 갱신.

## 맥락

본문 17개 장(ch01~17)의 개념 다이어그램은 ADR 0002 이래 **SVG를 코드로 작성 → `render_images.py`로 결정론 렌더 → PNG**를 원칙으로 삼았다. 한글 라벨이 많은 다이어그램에서 다음이 반복됐다.

1. **한글 타이포그래피 한계.** rsvg-convert 렌더는 한글 자간·줄바꿈·여백 제어가 약해, 비전 교정 루프(`codex exec -i`)를 거쳐도 발행 수준의 시각 품질에 못 미쳤다.
2. **겹침·정렬 비용.** LLM이 SVG 좌표를 눈 감고 찍어 화살표·텍스트·박스가 겹쳤고, 교정 루프가 17개 × 반복이라 비쌌다.
3. **대안의 품질 우위.** 저자가 ChatGPT(GPT-image)로 동일 다이어그램의 한국어판을 생성해 **전수 직접 검토**한 결과, 한글 가독성·여백·표지 조화가 SVG 렌더보다 분명히 우수했다(글리프 깨짐 거의 없음, 용어·캡션 일치 확인).

이 책은 결정론적 산출물(원칙·ch14)을 *가르치므로*, 본문 이미지를 비결정적 AI 래스터로 바꾸는 것은 자기모순의 위험이 있다. 그래서 "숨기기"가 아니라 "정직하게 예외로 문서화 + 자기채점 감점"으로 처리한다(이 책의 4부 자기해부 정신과 동일).

## 결정

1. **발행 본문 이미지 = ChatGPT 한국어 래스터.** 본문 `![]()`는 `assets/diagrams/chatgpt-renders/<slug>.ko.png`를 가리킨다. ch01~17 17개 경로를 일괄 교체했다(캡션 불변).
2. **SVG는 콘텐츠 소스로 보존.** `assets/diagrams/<slug>/NN-*.svg`와 렌더 PNG(`assets/screenshots/<slug>/`)는 **삭제하지 않는다.** SVG는 발행 래스터의 **콘텐츠 명세(무엇을 그릴지)** 이자 diff 가능한 설계 이력으로 남는다.
3. **생성 프롬프트 단일 원천.** `assets/diagrams/CHATGPT_IMAGE_PROMPTS.md`(표지-조화 스타일 + 장면 묘사)를 프롬프트 SoT로 둔다. 영어판(`.en.png`)도 동일 프롬프트로 생성해 보관.
4. **검수는 사람 게이트.** 래스터는 결정론으로 재현되지 않으므로 저자가 직접 눈 검수한다: 글리프·오타, 라벨 용어가 `verified-facts.md`와 일치(병합/황금 원칙/진실의 원천 등), 캡션-그림 일치. `verify.py`는 이미지 내용까지는 검사하지 않으므로 이 검수는 **사람의 책임**이다.
5. **자기채점 반영.** 4부(ch16·17)에서 이 하네스를 8원칙으로 채점할 때, "결정론적 산출물"(원칙·ch14) 축은 **본문 다이어그램이 예외임을 명시하고 감점**한다. 스크린샷·SVG 소스가 결정론을 유지하는 부분은 가점.

## 근거

- **독자 가치 > 내부 순수성.** 발행물의 1차 목표는 한국어 독자의 가독성이다. 결정론은 *수단*이지 그 자체가 목적이 아니며, 이 한 지점에서 품질이 더 큰 가치였다.
- **정직성 우선.** 예외를 숨기지 않고 ADR·규약·본문 자기채점에 드러내는 것이 이 책의 일관된 태도(비정본 카운트·"도출한 8원칙" 표기와 같은 결).
- **되돌리기 쉬움.** SVG 소스를 보존하므로, 향후 SVG 한글 렌더 품질이 개선되면 경로만 되돌려 결정론으로 복귀할 수 있다.

## 영향

- `manuscript/ch01~17` 이미지 경로 17개 교체. `verify.py` PASS(이미지 검사 없음). reviewed/published 상태·사실 불변.
- CLAUDE.md Rule 4, `conventions.md` §8(a)를 2트랙(SVG 소스 + ChatGPT 발행본)으로 갱신. "AI 래스터 금지" 단정 문구 제거.
- `assets/diagrams/chatgpt-renders/`(ko·en 각 17), `CHATGPT_IMAGE_PROMPTS.md` 신규 커밋.
- 발행 시 `upload_page_image`는 ko 래스터를 올린다(런북 경로 변경 없음 — `![]()`가 가리키는 파일을 그대로 사용).

## 대안 / 기각

- **SVG 결정론 고수(현행 유지)**: 한글 가독성이 발행 수준에 미달 → 기각(독자 가치 손해).
- **SVG를 계속 쓰되 한글 폰트 임베드/엔진 교체**: 투자 대비 품질 불확실, 17개 재작업 비용 큼 → 보류(향후 옵션으로 남김, SVG 보존으로 가능).
- **이미지 전면 제거**: 개념 다이어그램은 이 책의 학습 가치 핵심 → 기각.
- **예외를 문서화하지 않고 조용히 교체**: 책의 정직성·자기채점 원칙 위반 → 기각.
