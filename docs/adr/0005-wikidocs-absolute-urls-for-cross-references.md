# ADR 0005 — 본문 교차 참조를 위키독스 절대 URL 링크로 표기

- 상태: 채택
- 날짜: 2026-06-12
- 관련: ADR 0001(SoT). `docs/toc.json`의 페이지 ID(front-matter `wikidocs_page_id`)가 링크 대상의 진실의 원천.

## 맥락

"하네스 엔지니어링" 구글 검색 노출을 위한 SEO 점검(2026-06-12)에서 다음을 확인했다.

1. 장 페이지는 구글에 색인되지만, **책 대문(`/book/20064`)은 책 제목 그대로 검색해도 노출되지 않음** — 내부 링크가 약하다.
2. 본문의 장 간 교차 참조("13장", "12장의 SoT" 등)가 전부 플레인 텍스트라, 위키독스 발행본에서 내부 링크로 작동하지 않는다.
3. 구글 SEO Starter Guide는 서술형 앵커 텍스트의 내부 링크를 명시적으로 권장한다.

## 결정

1. **본문 산문·부록 표의 장 간 교차 참조를 `[N장](https://wikidocs.net/<page_id>)` 절대 URL 링크로 표기한다.** 적용 범위는 저자가 항목별로 승인한 곳(2026-06-12: ch03·05·13·14·15·16·17 본문 18곳 + 부록 B·C 표 전체). ch02 본문과 부록 A 표는 저자 결정으로 제외.
2. 부록 B·C의 `chNN` 표기는 링크 전환과 함께 `[N장](URL)`로 통일한다(문체 규칙 "chNN→NN장"과 정합).
3. 링크 대상 page_id는 각 원고 front-matter의 `wikidocs_page_id`와 일치해야 한다.

## 트레이드오프 (정직하게)

- **SoT에 외부 URL 결합**: manuscript(소스)가 발행처(위키독스) URL에 의존하게 된다. 페이지를 재생성해 page_id가 바뀌면 본문 링크를 일괄 수정해야 한다(grep `wikidocs.net/36` 으로 전수 탐색 가능).
- **로컬 미리보기**: 로컬 마크다운 뷰어에서 장 간 이동이 파일 점프가 아니라 웹 이동이 된다.
- 4부 자기채점 관점에서는 "산출물(발행본) 형식이 소스에 역류"한 사례로, ADR 0004와 같은 계열의 의도적·문서화된 예외다.

## 검증

- `scripts/verify.py`의 링크 검증이 본문 링크 무결성을 점검한다.
- 같은 장 재발행 시 page_id는 변하지 않으므로(`update_page` 원칙, CLAUDE.md Rule 5) 링크는 안정적이다.
